# HEALTHPULSE — Personal Health Monitoring Dashboard

A professional frontend-only health monitoring dashboard built with HTML5, CSS3, Vanilla JavaScript and Chart.js.

## Features
- Responsive SaaS-style dashboard
- Heart rate, blood pressure, weight and oxygen summary
- BMI calculator
- Health readings table with add/delete
- Water intake tracker
- Activity/step tracker
- Sleep overview
- Interactive Chart.js visualizations
- Daily goals and health insights
- Dark/light theme
- LocalStorage persistence
- Printable health report
- Settings and reset functionality

## Technology
HTML5 • CSS3 • Vanilla JavaScript • Chart.js • LocalStorage

## Run
Open `index.html` directly in a modern browser. No backend or build step is required.

## Data
User-entered data is stored locally in the browser using LocalStorage. No server or database is used.
